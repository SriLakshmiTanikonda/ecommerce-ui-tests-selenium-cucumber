# ecommerce-ui-tests-selenium-cucumber
BDD UI test automation framework in Java 17 with Selenium 4, Cucumber 7 and TestNG. Tests an e-commerce store (login, cart, checkout, tax totals) and tricky browser cases (waits, alerts, windows, tables). Page Object Model, parallel runs, JSON/Excel test data, Allure reports, failed-test retry, and CI with GitHub Actions and Jenkins.
